# Heaps

## What is a Heap?
A **heap** is a special kind of **binary tree** used to manage priority efficiently.

## Properties
- **Complete Binary Tree:** All levels are filled except possibly the last.
- **Heap Property:**
  - **Min-Heap:** Parent is smaller than children.
  - **Max-Heap:** Parent is larger than children.

## Common Uses
- Priority queues.
- Scheduling algorithms.
- Efficiently finding min/max in a dataset.
- Heap sort algorithm.
