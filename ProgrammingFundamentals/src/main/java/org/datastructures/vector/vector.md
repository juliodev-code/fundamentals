# Vectors
## What is a Vector?
A **vector** is a **dynamic array** that can **grow or shrink** as needed.

## Characteristics
- Stores elements in **contiguous memory**.
- Automatically resizes when full.
- Supports random access by index.

## Advantages
- Fast access by index.
- Flexible size.
- Built-in methods for adding/removing elements.

## Disadvantages
- Resizing can be costly (copying data).
- Inserting/removing in the middle is slow.

## Common Uses
- Storing dynamic lists of data.
- Implementing other data structures.
