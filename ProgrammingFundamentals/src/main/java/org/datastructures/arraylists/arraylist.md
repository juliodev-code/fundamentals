# ArrayLists

## What is an ArrayList?
An **ArrayList** is basically a **resizable array** that makes it easy to add, remove, and access elements.

## Characteristics
- Stores elements in order.
- Automatically increases its capacity when needed.
- Allows duplicates and `null` values.

## Key Operations
- Add or remove elements.
- Get or set an element by index.
- Iterate through the list.

## Advantages
- Simple and fast for random access.
- Resizes automatically.

## Disadvantages
- Slow insertions/removals in the middle.
- Not thread-safe by default.

## Common Uses
- Dynamic lists of data (like shopping carts or playlists).
