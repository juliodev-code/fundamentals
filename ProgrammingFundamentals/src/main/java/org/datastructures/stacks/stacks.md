# Stacks

## What is a Stack?
A **stack** is a data structure that follows the rule:
> **LIFO – Last In, First Out**

It’s like a stack of plates: the last plate you put on top is the first one you take off.

## Key Operations
- **Push:** Add an item to the top.
- **Pop:** Remove the top item.
- **Peek (Top):** See the top item without removing it.
- **isEmpty:** Check if the stack is empty.

## Common Uses
- Undo/Redo in text editors.
- Backtracking in algorithms.
- Function call management (call stack).
- Expression evaluation (e.g., parentheses balance).
