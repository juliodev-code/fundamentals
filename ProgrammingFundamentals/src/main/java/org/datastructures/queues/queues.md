# Queues

## What is a Queue?
A **queue** is a data structure that follows:
> **FIFO – First In, First Out**

It’s like a line at a store: the first person to enter is the first to be served.

## Key Operations
- **Enqueue:** Add an item to the back.
- **Dequeue:** Remove an item from the front.
- **Front/Peek:** Look at the first item.
- **isEmpty:** Check if it’s empty.

## Types of Queues
- **Circular Queue:** The end connects to the front for efficient space use.
- **Priority Queue:** Items are served based on priority, not order.
- **Deque (Double-Ended Queue):** Add/remove items from both ends.

## Common Uses
- Task scheduling.
- Print spooling.
- Breadth-First Search in graphs.
- Message queues in systems.
